# Maggot

binaryimage's mangle synth for Akai MPC standalone hardware. It's beautiful underneath and filthy
on top, and you can tear everything apart live. An original synth with an 8-page touch UI on its
own textured skin, and 100 presets.

## Install
MPC OS 3.10.1 or later. On the MPC, go to Preferences > Enhancements (Beta) and turn on Enable
Enhancements and External Plugin Support. Copy the `binaryimage - VST - Maggot` folder into
`VST2 Plugins` at the root of a drive, restart, make a plugin track, and pick Maggot.

## Pages
| Page | What's on it |
|---|---|
| MAGGOT | Volume, Poly/Mono, bend, spread, **WRECK**, wheel destination, aftertouch, **Glitch**, and the **TAPE STOP / STUTTER / REVERSE / FREEZE** buttons |
| OSC | Osc 1 (sine-tri-saw-square morph, wavefolder), Osc 2 (morph, semi/fine, 3-voice stack), FM, ring, noise (white/pink/crackle/dust + color) |
| RES/FLT | Note-tuned resonator (mix, decay, tone, pitch); LP/BP/HP/Notch filter with drive, env, key track, audio-rate Filter FM, velocity |
| ENV | Amp ADSR, filter ADSR, AD mod envelope with its own destination |
| LFO | Two LFOs (6 shapes, LFO 1 can tempo-sync), each with a destination and amount |
| ARP | Leviasynth-style arp: 8 modes (Up, Down, UpDown, Converge, Diverge, Random, Order, Chord), octaves, gate, swing, pattern Length (runs against the held notes for polymeters), ratchets + probability, note probability (rests), random octave jumps, Mutate, Hold, accent |
| MANGLE | Grind, bit depth, downsample, wow, ring mod, granular Smear (amount, size, pitch scatter), tape stop time, stutter and reverse lengths |
| SPACE | Ping-pong delay and reverb |

## Tearing it apart
- **Tape Stop** slows everything to a halt, pitch and all, over Stop Time. Let go and it spins
  back up.
- **Stutter** loops the last Stutter Div of audio. **Reverse** plays the last Reverse Div
  backwards. **Freeze** holds a short loop as a drone.
- **Glitch** rolls the dice every 16th note and fires random stutters, reverses and the odd
  tape stop by itself.
- **WRECK** pushes the fold, grind, crush, ring, smear, wow and glitch all at once. The mod
  wheel drives WRECK by default (Wheel Dest).

## Presets (100)
BA bass (14), RF riffs/heavy (10), PD pads (14), BL bells/resonator (10), AR weird arps (16),
MG mangle performance (10), DR drones (10), PC percussion (8), FX (7), plus Init. All 100 are
level-matched. They're generated by `tools/make_presets.py`, so edit that script, not the .inc.

## CPU
On a desktop CPU the heaviest preset is under 5 % of one core with a 4-note chord. The MPC is
slower, so check on the device, especially with Smear and big Res Decay pads.
