binaryimage Plugins for the PC
==============================

Your MPC plugins as VST3s for Ableton (or any VST3 host) on Windows:

  Synths:  Janus, Maggot, Legion
  Effects: Grendel, Ouroboros, Fenrir, Moloch, Mare, Banshee

They run the same sound engine as the MPC versions, with the same presets, so a sound
made on the MPC sounds the same here. The window has the same tabs, knobs and skin as the
MPC screen.

Install
-------
Run the installer. The plugins go into C:\Program Files\Common Files\VST3\binaryimage,
where Ableton finds VST3s by itself. In Ableton: Options > Preferences > Plug-Ins, make
sure "Use VST3 Plug-in System Folders" is on, then Rescan. They show up under Plug-Ins >
binaryimage.

Using them
----------
- Presets: the drop-down at the top, or the < > arrows. Ableton's own preset saving works too.
- Tabs: same pages as on the MPC.
- Knobs: drag up and down. Hold Shift for fine moves. Double-click a knob to reset it.
  The mouse wheel works too.
- Faders: click or drag.
- Switches and the Poly/Mono style buttons: click.
- Drop-downs (like Wheel Dest or Arp Mode): click and pick.
- Drag the bottom-right corner to make the window bigger or smaller.
- Every knob can be automated in Ableton and mapped to a controller.

They're unsigned, like the other BC apps, so Windows or your antivirus may ask about the
installer the first time.
